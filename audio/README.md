# 音效文件目录

请将以下音效文件放入此目录（支持 .wav、.ogg、.mp3 格式）：

## 必需音效文件列表

| 文件名 | 用途 | 建议时长 |
|--------|------|----------|
| card_play.wav | 出牌音效 | 0.2-0.5秒 |
| card_draw.wav | 抽牌音效 | 0.2-0.5秒 |
| card_flip.wav | 翻牌音效 | 0.2-0.3秒 |
| card_select.wav | 选牌音效 | 0.1-0.2秒 |
| boss_attack.wav | Boss攻击音效 | 0.3-0.5秒 |
| boss_defeat.wav | Boss击败音效 | 0.5-1秒 |
| boss_spawn.wav | Boss出现音效 | 0.3-0.5秒 |
| damage.wav | 伤害音效 | 0.2-0.3秒 |
| shield.wav | 黑桃护盾音效 | 0.2-0.3秒 |
| heal.wav | 红心恢复音效 | 0.2-0.3秒 |
| draw_cards.wav | 方块抽牌音效 | 0.2-0.5秒 |
| double_damage.wav | 梅花翻倍音效 | 0.2-0.3秒 |
| joker_play.wav | Joker出牌音效 | 0.3-0.5秒 |
| win.wav | 胜利音效 | 1-2秒 |
| lose.wav | 失败音效 | 1-2秒 |
| button_click.wav | 按钮点击音效 | 0.1-0.2秒 |
| turn_change.wav | 回合切换音效 | 0.2-0.3秒 |

## 推荐音效来源

- [Freesound.org](https://freesound.org) - 免费音效库
- [OpenGameArt.org](https://opengameart.org) - 游戏素材库
- [Zapsplat.com](https://zapsplat.com) - 免费音效

## 注意事项

1. 音效文件应尽量简短，避免影响游戏流畅度
2. 建议使用 .wav 或 .ogg 格式（Godot原生支持）
3. 如果暂时没有音效文件，游戏仍可正常运行（仅输出警告日志）

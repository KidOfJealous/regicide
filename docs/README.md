# Regicide 项目文档

## 项目概述

Regicide（弑君）是一款基于Godot引擎开发的卡牌游戏。玩家需要通过合理的出牌策略击败所有的Boss牌来获得胜利。

## 核心游戏系统

### 游戏规则
1. 玩家初始手牌为7张
2. 玩家每回合需要出牌攻击Boss
3. 出牌规则：
   - 可以出一张牌
   - 可以出一张牌（可以是A）和若干A
   - 可以出多张相同数值的牌，但总和不能超过10
4. 当玩家没有手牌时判负（单人模式规则）

### 卡牌系统
- **普通牌**：四种花色（黑桃、红心、方块、梅花），数值1-10（A, 2-10）
- **Boss牌**：三种类型（J, Q, K），四种花色，数值分别为10, 15, 20

### 牌堆系统
- **抽牌堆**：存放未使用的普通牌
- **弃牌堆**：存放玩家弃掉的牌
- **处理区**：存放玩家出过的牌
- **Boss区**：当前激活的Boss牌

## 技术实现

### 代码结构
```
scripts/
├── card_manager.gd      # 卡牌管理器
├── play_ground.gd       # 游戏主逻辑
├── player.gd            # 玩家逻辑
├── hand.gd              # 手牌管理
├── deck.gd              # 抽牌堆
├── discard.gd           # 弃牌堆
├── card_field.gd        # 处理区
├── boss_deck.gd         # Boss牌堆
├── card.gd              # 卡牌类
├── card_data.gd         # 卡牌数据和规则
```

### 关键技术点

#### 卡牌有效性检查
```gdscript
# isValidCards函数实现三种出牌规则：
# 1. 出一张牌
# 2. 出一张牌（可以是A）和若干A
# 3. 出一些相同数值的牌且总数值和不能超过上界
```

#### 区域卡牌层叠显示
所有区域（处理区和弃牌区）的卡牌都以层叠方式显示，重叠比例为10%。

#### 阶段文本提示
在Player阶段和Defend阶段，按钮上方会显示相应的操作提示。

## 开发规范

### 代码规范
- 使用Godot 4.x GDScript语法
- 遵循Godot节点初始化顺序规范
- 避免在初始化完成前触发业务逻辑

### 命名规范
- 类名使用首字母大写驼峰命名法（如Player）
- 函数名使用下划线命名法（如wait_for_play）
- 常量使用全大写加下划线命名法（如CARD_SUM_MAX）

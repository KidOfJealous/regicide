## 编码规范

### 命名约定
1. **类名**：使用首字母大写的驼峰命名法（PascalCase）
   ```gdscript
   class_name Player extends Node2D
   ```

2. **函数名**：使用下划线命名法（snake_case）
   ```gdscript
   func wait_for_play() -> Array[Card]
   ```

3. **变量名**：使用下划线命名法（snake_case）
   ```gdscript
   var current_boss: Card = null
   ```

4. **常量名**：使用全大写字母加下划线命名法（UPPER_CASE）
   ```gdscript
   const CARD_SUM_MAX = 10
   ```

### 代码格式
1. **缩进**：使用制表符（Tab）进行缩进
2. **括号**：左括号与函数名同行，右括号独立一行
   ```gdscript
   func example_function() -> void:
       if condition:
           # code here
       pass
   ```
3. **注释**：使用中文注释，重要逻辑必须添加注释
   ```gdscript
   # 更新状态标签文本
   func _update_status_label(discard_target: int = 0) -> void:
   ```

### 最佳实践
1. **信号使用**：优先使用信号进行模块间通信
2. **节点引用**：使用@onready声明节点引用
   ```gdscript
   @onready var button: Button = $Button
   ```
3. **错误处理**：关键操作添加错误检查
   ```gdscript
   if player == null:
       push_error("Player node not found!")
   ```

## 常见问题

### 节点初始化顺序问题
**问题描述**：在_ready函数中访问其他节点时出现null引用

**解决方案**：
1. 使用信号机制协调初始化顺序
2. 延迟初始化到_process函数中
3. 确保节点树结构正确

### 卡牌交互问题
**问题描述**：卡牌无法正确响应鼠标事件

**解决方案**：
1. 检查Area2D和CollisionShape2D配置
2. 验证物理层和掩码设置
3. 确认卡牌的disabled状态

### 显示异常问题
**问题描述**：卡牌显示位置或层级不正确

**解决方案**：
1. 检查z_index设置
2. 验证position属性更新逻辑
3. 确认锚点和边距设置
